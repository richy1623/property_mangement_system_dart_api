# Changelog

## 0.0.1+1

### Added

* Initial release of the `property_management_system_dart_api` package.
* **Core API Stack:** Implemented necessary packages for API client generation:
    * `retrofit` and `retrofit_generator` for creating the type-safe client methods.
    * `dio` for robust HTTP handling.
    * `swagger_parser` for handling OpenAPI/Swagger schema definitions.
* **Data Handling:** Implemented packages for data formatting and modeling:
    * `json_annotation` for automated JSON serialization/deserialization.
    * `intl` for internationalization utilities.
* **Tooling:** Setup `build_runner` for running code generation, and `flutter_lints` for code quality checks.
